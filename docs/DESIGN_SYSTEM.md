# Nuvex Design System

Direction: modern, premium, minimal e-commerce. Brand palette and logo should be driven by actual brand assets when supplied.

## Foundations
- Mobile-first breakpoints, responsive container and a consistent spacing scale.
- Typography with readable 16px body baseline, concise headings and high contrast.
- Neutral background, one restrained accent color, consistent card radius and buttons.
- Clear visual hierarchy: hero > categories > featured products > editorial content.
- No decorative UI at the expense of navigation, usability or performance.

## Components
Header, Navigation, ProductCard, Price, CategoryCard, Search, Breadcrumbs, Pagination, EmptyState, Skeleton, Cart and Checkout components should share primitives and tokens.

## Interaction
Keyboard navigation, visible focus, usable tap targets, reduced motion, stable loading states and meaningful validation feedback.

## Acceptance checklist
- Responsive at 360px, tablet and desktop.
- Contrast, headings, labels, alt text, keyboard navigation reviewed.
- No broken/placeholder fake product details.
- Metadata, canonical and crawl directives reviewed.
- No secrets or backend admin keys sent to client.
